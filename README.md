# Recaton

Шаблон пользовательского приложения для управления роботом через MaixCam.
Связь с периферией выполняется библиотекой `service`.

## Запуск

```python
import time

from service import MaixcamLink


link = MaixcamLink()
link.command.set_enabled("motors")
link.command.set_all_speeds(0)
link.start()

try:
    while link.running:
        telemetry = link.read_telemetry()

        # Логика управления соревнования:
        # link.command.set_speed(0, 250)
        # link.command.set_all_speeds(250)
        # link.command.set_enabled("line", "motors")

        time.sleep(0.010)
finally:
    link.command.set_safe()
    link.stop()
```

`main.py` содержит тот же минимальный шаблон и является точкой входа
пользовательской программы.

## Управление

`MaixcamLink` запускает один фоновый обмен данными. Методы
`command` только изменяют состояние следующего кадра:

```python
link.command.set_speed(motor, speed)  # motor: 0..3, speed: -1000..1000
link.command.set_all_speeds(speed)
link.command.set_enabled("motors", "line")
link.command.set_enable_group("motors", False)
link.command.set_safe()
```

Доступные группы: `motors`, `line`, `motor_current`, `battery`,
`distance_sensor`.

`set_safe()` отключает все группы и устанавливает нулевую скорость всех
моторов.

## Enable-биты

Именованный объект `ENABLE` позволяет собирать маску без ручного указания
номеров битов:

| Имя | Бит | Назначение |
|---|---:|---|
| `ENABLE.MOTORS` | 0 | Разрешение драйверов моторов и PWM |
| `ENABLE.LINE` | 1 | Подсветка и значения линейных датчиков |
| `ENABLE.MOTOR_CURRENT` | 2 | Значения токов моторов |
| `ENABLE.BATTERY` | 4 | Значения батарейных входов |
| `ENABLE.DISTANCE_SENSOR` | 5 | Измерение расстояния |

Бит разрешения является частью команды, которую MaixCam отправляет периферии:

- `1` включает группу и разрешает её работу и передачу связанных с ней данных
  в telemetry-кадрах;
- `0` отключает группу, поэтому соответствующий источник не используется.

Для моторов бит `MOTORS` разрешает движение моторов. Для получания значений датчиков линии и расстояния биты `LINE` и `DISTANCE_SENSOR`. Биты `MOTOR_CURRENT` и `BATTERY` сообщают системе о необходимости передать значения токов моторов и текущего напряжения аккумуляторов.

Группу можно включить или отключить по имени:

```python
link.command.set_enable_group("line", True)   # включить обмен значениями
link.command.set_enable_group("line", False)  # отключить группу
```

При вызове `set_enabled()` маска заменяется полностью. Все группы, которые не
переданы в аргументах, отключаются:

```python
link.command.set_enabled("motors", "line")
# motors и line включены, остальные доступные группы отключены
```

Пример комбинированной маски:

```python
from service import ENABLE

link.command.set_enable_mask(ENABLE.LINE | ENABLE.MOTORS)
```

## MaixcamLink

`MaixcamLink(auto_reset=False)` создаёт объект связи с периферией. Фоновый
обмен не запускается до вызова `start()`. При `auto_reset=True` перед запуском
сначала выполняется инициализация периферии.

| Метод или свойство | Описание |
|---|---|
| `start()` | Запускает фоновый обмен с частотой 100 Гц. Повторный вызов во время работы игнорируется. |
| `stop()` | Останавливает обмен и ожидает завершения фонового потока. Вызывайте в `finally`. |
| `reset()` | Приостанавливает новые передачи, завершает текущую, отправляет безопасную команду, переинициализирует периферию и возобновляет обмен. |
| `running` | Свойство только для чтения. Равно `True`, пока обмен активен. |
| `read_telemetry()` | Возвращает независимую копию последнего корректного telemetry-кадра. |
| `button_get_state()` | Возвращает состояние кнопки MaixCam с программным подавлением дребезга. |
| `stats()` | Возвращает копию статистики обмена и последнюю ошибку передачи. |
| `command` | Объект `CommandState` для настройки следующих команд. Используйте его методы, не изменяйте внутренние списки. |
| `telemetry` | Кэш `TelemetryState`. Предпочтительный способ чтения - `read_telemetry()`. |

## CommandState

Команды потокобезопасны. Индексы моторов находятся в диапазоне `0..3`,
скорость - в диапазоне `-1000..1000`. Отрицательное и положительное значения
задают противоположные направления, а `0` останавливает мотор.

| Метод или свойство | Описание |
|---|---|
| `set_speed(motor, speed)` | Задаёт скорость одного мотора. Вызывает `ValueError` при неверном индексе или диапазоне. |
| `set_all_speeds(speed)` | Задаёт одинаковую скорость всем четырём моторам. |
| `set_enable_mask(mask)` | Заменяет полную 16-битную маску разрешений. |
| `set_enable_bit(bit, enabled)` | Включает или выключает один бит маски в диапазоне `0..15`. |
| `set_enable_group(name, enabled=True)` | Включает или выключает именованную группу. |
| `set_enabled(*names)` | Заменяет маску перечисленными именами; без аргументов отключает все группы. |
| `set_safe()` | Атомарно отключает все группы и обнуляет скорости. Используйте перед остановкой. |
| `frame_flags` | Читаемые и изменяемые 8-битные прикладные флаги кадра. |
| `frame_counter` | Счётчик кадров, назначаемый рабочим потоком. Только для чтения. |
| `enable_mask` | Текущая маска разрешений. Доступна для чтения и записи. |
| `motor_speed` | Кортеж текущих скоростей четырёх моторов. Только для чтения. |

## Телеметрия

`link.read_telemetry()` возвращает независимый снимок последнего принятого
кадра. Доступны поля `line`, `motor_current`, `battery`, `distance_sensor`,
`active_enable_mask`, `error_flags` и `raw`.

Поля telemetry-снимка:

| Поле | Назначение |
|---|---|
| `protocol_version` | Версия протокола. |
| `telemetry_flags` | Служебные флаги telemetry-кадра. |
| `command_frame_counter_echo` | Номер последней принятой команды. |
| `active_enable_mask` | Маска, фактически применённая периферией. |
| `error_flags` | Битовая маска ошибок связи и доступных устройств. |
| `line` | Четыре значения линейных датчиков. |
| `motor_current` | Четыре значения тока моторов. |
| `battery` | Два значения батарейных входов. |
| `distance_sensor` | Последнее значение измерения расстояния. |
| `raw` | Полный проверенный 80-байтный telemetry-кадр. |

## Пересчёт ADC-значений

Поля `motor_current` и `battery` содержат сырые 12-битные ADC-коды `R` в
диапазоне `0..4095`. Для расчёта используется номинальное опорное напряжение
`3300 mV`:

```text
U_ADC_mV = R * 3300 / 4095
```

### Токи моторов

Для каналов `motor_current` используется шкала `0..3.3 V` на входе ADC,
соответствующая диапазону `0..800 mA`:

```text
I_mA = R_CURRENT * 800 / 4095
```

Пример обработки всех четырёх каналов:

```python
currents_ma = tuple(value * 800 / 4095 for value in telemetry.motor_current)
```

### Напряжение аккумуляторов

Для восстановления напряжения аккумулятора нужно учитывать резистивный
делитель между аккумулятором и входом ADC:

- `battery[0]` (`AKB1`, `VCC_IN`): `10 kOhm` и `18 kOhm`, коэффициент `28 / 10`;
- `battery[1]` (`AKB2`, `MID`): `10 kOhm` и `10 kOhm`, коэффициент `20 / 10`.

Формулы дают напряжение аккумулятора в `mV`:

```text
VCC_IN_mV = R_AKB1 * 3300 / 4095 * 28 / 10
MID_mV    = R_AKB2 * 3300 / 4095 * 20 / 10
```

Пример обработки:

```python
akb1_mv = telemetry.battery[0] * 3300 * 28 / (4095 * 10)
akb2_mv = telemetry.battery[1] * 3300 * 20 / (4095 * 10)
```

Сначала применяется пересчёт кода ADC в напряжение на входе микроконтроллера,
затем учитывается коэффициент внешнего делителя. Не применяйте коэффициент
делителя к значениям `motor_current`.

Состояние обмена можно получить через `link.stats()`. Для перезапуска обмена данными вызовите
`link.reset()`. Перед завершением приложения всегда вызывайте `set_safe()` и
`stop()`.

`LinkStats` содержит следующие поля:

| Поле | Назначение |
|---|---|
| `cycles` | Количество успешных циклических обменов. |
| `valid_frames` | Количество успешно разобранных telemetry-кадров. |
| `transfer_errors` | Количество ошибок передачи или разбора. |
| `last_error` | Текст последней ошибки или `None`. |
